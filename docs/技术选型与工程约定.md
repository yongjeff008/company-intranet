## 设计与工程方向

- 产品首先是可配置 CMS，企业内网是首个应用场景。
- IT 后台维护模板、页面布局、模块、部门与授权；业务后台维护内容；普通用户访问前台。
- React 负责页面交互，.NET 负责业务规则、服务端权限与 MySQL 数据访问。
- 模板面向 IT 提供 HTML/CSS 与受控字段绑定，不能要求 IT 编写 React 组件才能修改模板。
- 内置模板应默认适配桌面、平板和手机；IT 日常选择模板不需要另外编写响应式 CSS。模板代码自定义后需要检查各尺寸效果。
- 前台模板和后台界面可以有不同视觉设计，但应保持权限、内容及配置接口一致。

上述方向承接已有需求讨论，具体实现仍在工程设计阶段。

## 本次工程落地选择

用户授权开工后，为完成可运行的首版，采用以下实现选择：.NET SDK 10.0.403 / ASP.NET Core 10、Dapper 2.1.66、MySqlConnector 2.6.2、MySQL 8.4、React 19.3.1、TypeScript 7.0.2、Vite 8.3.5、Tiptap 3.32.2、DOMPurify 3.4.17、HtmlSanitizer 9.2.1039。前端采用自定义 CSS；2026-11-03 扩展为四季、节日、自选颜色及黑白共十套主题，通过语义 CSS 变量统一配色；构建按路由拆分，业务编辑器按需加载。

后端采用模块划分的单体应用，数据库将用户、部门授权、文档、版本、素材、参与记录、答卷和日志分别存表；业务类型字段与页面配置保存为 JSON 文本，保留草稿和发布快照。模板使用受控占位字段，CSS 在 Shadow DOM 内隔离并限制外部资源。数据访问选用 Dapper，避免依赖尚未验证的 EF Core/MySQL 驱动组合。

前台与双后台共用 React 工程和 .NET API，通过服务端权限区分。生产构建的静态文件由 ASP.NET Core 托管；Node 仅用于开发与构建。当前预览仅监听本机地址，数据库端口也仅绑定回环地址。

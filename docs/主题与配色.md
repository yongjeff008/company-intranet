确认日期：2026-11-03。管理员在「IT 配置中心 → 站点设置」选择预设配色，或继续使用自选主题色。选择时只在预览中生效，「保存并发布」后更新全站工作空间。

每套预设包含主色、辅助色、第三强调色、深色、背景、浅色面板、边框和文本色。预设通过语义 CSS 变量统一控制导航、按钮、背景、门户欢迎区与内置模块，而非只替换一个按钮颜色。主题定义见 `frontend/src/themes.tsx`，共用主题样式见 `frontend/src/themes.css`。

新闻与跑马灯使用主色，公告与文件使用辅助色，视频与问卷使用第三强调色。预设主题暂时接管内置模块颜色，但不改写模块保存的强调色与背景；切回自选主题色即可恢复。自定义 HTML/CSS 模板保留原有设计，特殊黑白模式统一在显示层转为灰阶，原始素材不变。

## 操作与生效

1. 管理员进入站点设置，选择主题卡片；右侧展示演示门户，不创建任何业务内容。
2. 选择「自选主题色」时显示颜色选择器。过浅颜色在界面中自动加深，保证白色按钮文字可读；保存的品牌色不被改写。
3. 点击「保存并发布」，站点名称、文案和主题一起发布，当前管理员界面立即更新。
4. 其他用户刷新页面后看到新主题；首页、部门空间、内容中心及管理工作空间共用当前已发布主题。登录前页面仍使用默认样式。
5. 季节与节日主题均手动选择，没有自动按日期切换。黑白模式发布后，管理界面和主题预览也遵循灰阶显示，切回彩色主题并发布后恢复彩色。

旧配置没有 `theme` 字段时按 `custom`（自选颜色）处理，不需要数据库结构迁移。服务端只接收十种受支持的主题标识，普通用户无法保存站点配置，主题草稿不会泄漏给普通用户。

## 验证

- 集成验证旧配置兼容、无效主题拒绝、普通用户越权拦截、草稿与发布隔离以及门户接口配色一致。
- 浏览器验证全部主题可选择、预览不影响已发布页面、发布后普通用户获得三种模块强调色、390px 手机无横向溢出、黑白模式和固定导航，以及切回自选颜色恢复模块原配色。

## 已实现的首版流程

| 范围 | 当前能力 |
| --- | --- |
| 工程 | 隔离 .NET 10 SDK、React/TypeScript/Vite、独立 MySQL 8.4、依赖锁文件、初始化与启动脚本 |
| 登录与权限 | 本地账号、随机首次管理员密码、密码哈希、Cookie、CSRF、登录限流；IT/业务/普通用户界面及服务端权限；授权变更使旧会话失效 |
| 部门与账号 | 创建、编辑、排序及停用部门；创建用户、配置角色、多个部门授权与独立的问卷结果权限 |
| 站点主题 | 十套主题、语义配色、模块三色搭配、局部实时预览与发布；黑白显示覆盖媒体及自定义模板，切回自选色恢复模块保存配色 |
| 页面配置 | 首页及部门页，舒展/紧凑布局；添加、移动、复制、移除模块；宽度、样式、来源、分类、数量、颜色、显隐与空状态设置 |
| 发布与版本 | 页面和内容独立草稿、发布、下线与版本历史；乐观并发检查；历史恢复为草稿，再发布生效 |
| 模板 | 内置列表/卡片/首条突出；自定义模块 HTML/CSS；受控变量绑定、预览、HTML 清洗与 CSS 隔离；页面绑定已发布模板的具体版本 |
| 内容维护 | 六类内容的录入与发布，富文本基础编辑，分类、作者、有效期、置顶、封面和附件；内容列表查询与草稿预览 |
| 新闻与公告 | 发布后按模块筛选自动展示；同一新闻可被列表和跑马灯复用；过期内容从当前前台撤回 |
| 视频 | 上传 MP4/WebM 或引用 HTTP/HTTPS 地址；封面、正文与相关资料；受保护本地视频支持范围请求 |
| 正式文件 | 文号、发文单位与日期、原件附件、有效状态、替代记录字段和更正说明；原件变更可从内容历史追溯 |
| 跑马灯 | 引用新闻/公告或独立短消息；滚动/静态、暂停、键盘聚焦暂停和减少动态效果支持 |
| 问卷 | 六种基础题型、实名/登录匿名、开放时间、提前关闭、最终提交；服务端资格/范围/必填校验，重复提交约束，题目结构冻结，统计及 CSV 导出 |
| 素材 | 部门上传库、类型与大小限制、文件下载鉴权；有历史引用的素材不允许直接删除；没有公开上传目录 |
| 前台 | 首页、部门页、内容列表、详情、标题/摘要/文号检索；手机导航与响应式布局；真实空站点，不自动发布示例业务内容 |
| 日志 | 登录、部门/账号修改、配置及内容发布、模板变更、上传删除和问卷导出等关键操作记录 |

## 使用起点

本机启动地址为 http://localhost:5088 。初始化不创建部门、新闻、附件或问卷。先用 `admin` 配置站点，首次密码见本地 `.env`，再创建部门管理员完成业务内容录入。

详细命令与工程结构见 [README](../README.md)，产品需求仍以评审文档及后续用户指令为准。
